# TK 素材工坊 · TK Studio

**采集 · 去水印 · 高清修复，一站式素材工作台。**

把原本两个独立的 Windows 程序 —— **TK 作品链接采集器**（v1.2.1）与
**TK 去水印高清程序**（v4.0.4）—— 合并为一套统一应用。
一个窗口、一套导航、一套配色，两类能力在同一个界面里协同使用。

- **版本**：v1.4.4
- **形态**：本地桌面程序（WebView2 原生窗口 + 本地服务，数据全部留在本机，不上传）
- **便携**：文件夹即程序 —— 自带 Python 运行时、依赖环境**与浏览器内核**，
  拷到别的电脑（哪怕从没装过 Python 或 Playwright）即可直接运行

> 📖 **从源码安装 → [INSTALL.md](INSTALL.md)** —— 完整的分步安装说明
> （环境要求、依赖安装、模型权重下载清单、ffmpeg 准备、自检与排错）
>
> ⚠️ **本仓库只收录源码与文档**：虚拟环境、浏览器内核、模型权重、ffmpeg 都未入库
> （合计约 6.9 GB），需要按 INSTALL.md 自行准备。

## 一、快速开始

> ⚠️ **本仓库是「源码仓库」**，不含虚拟环境、模型权重、浏览器内核与 ffmpeg
> （合计约 6.9 GB，超出 GitHub 限制）。**没有任何"下载即用"的完整版** ——
> 不论走哪条路，都要先在本机把这几个大件准备出来，见
> **[INSTALL.md](INSTALL.md)**。

### 路线 A · 装好源码（推荐）

```bat
:: 1) 取源码
git clone https://github.com/chenquaerere/tk-studio.git
cd tk-studio

:: 2) 建虚拟环境（Python 3.10 64 位）
python -m venv venv

:: 3) ★ 先装 PyTorch，再装其余依赖 —— 顺序不能反
venv\Scripts\python.exe -m pip install ^
    torch==2.11.0+cu128 torchvision==0.26.0+cu128 ^
    --index-url https://download.pytorch.org/whl/cu128
venv\Scripts\python.exe -m pip install -r requirements.txt

:: 4) 采集要用的浏览器内核（约 150 MB）
venv\Scripts\python.exe -m playwright install chromium

:: 5) 启动
venv\Scripts\python.exe desktop.py
```

逐步说明、CPU 版 torch、国内镜像、ffmpeg、排错 —— 全部在
**[INSTALL.md](INSTALL.md)**（第 1~6 步）。

装完之后，也可以直接**双击 `TK素材工坊.exe`** 启动（仓库自带的托盘启动器）——
它会自己找 `venv\Scripts\python.exe`，不用再开命令行。

### 路线 B · 做成便携完整版（发给别人 / 换机器，约 6.9 GB）

完整版压缩包**不进仓库**（GitHub 单文件上限 2 GB），需要自己打：

```bat
:: 前提：先按路线 A 装好，并下完模型（见下一节）与 ffmpeg
venv\Scripts\python.exe scripts\package.py
:: 产物：上级目录的  TK素材工坊_v1.4.4.zip
```

`package.py` 会自动**排除用户数据**（`data\` `downloads\` `backups\` `exports\`
`links_log\`），并内置两条硬闸门：用户数据混入 → 退出码 2；随身内核不在清单 → 退出码 3。
先加 `--dry-run` 可以只看清单不打包。

那个 zip 就是"文件夹即程序"形态 —— 拷到别的 Windows 上解压即用，
连 Python 都不用装。

### 路线 C · 只补充「高清修复」的模型

见下一节，一句话：


## 二、模型权重怎么装（「高清修复」用）

**只做链接采集 / 去水印的可以跳过整节** —— 这两块不需要任何模型。

模型放在 `models\`，人脸修复的辅助权重放在 `gfpgan\weights\`。三种方式任选：

### 方式 1 · 什么都不做 ★ 最省事

**程序会自己下载。** 第一次用到某个模型时（例如在「高清修复」页选了一个还没下过的模型，
或勾上「人脸修复」），程序会把它下到 `models\`，带多源回退与断点重来，
界面上能看到进度。所以"能跑起来"其实不缺这一步。

适合：网络还行、只想用默认模型试试。

### 方式 2 · 提前一次性下好 ★ 推荐慢网 / 离线 / 打包前

```bat
:: 先看清单和当前状态（不下载）
venv\Scripts\python.exe scripts\fetch_models.py --list

:: 下载全部「已接入」模型（5 个，约 484 MB）
venv\Scripts\python.exe scripts\fetch_models.py

:: 只下最小可用（默认模型，1 个，约 5 MB）
venv\Scripts\python.exe scripts\fetch_models.py --min

:: 连可选模型一起（9 个）、并备好人脸修复辅助权重（＋约 186 MB）
venv\Scripts\python.exe scripts\fetch_models.py --all --face

:: 只下某一个 / 走代理
venv\Scripts\python.exe scripts\fetch_models.py --key GFPGANv1.4
venv\Scripts\python.exe scripts\fetch_models.py --proxy http://127.0.0.1:11304
```

已就位的会跳过，失败的会重试 —— 中断后重跑同一命令即可续上。

### 方式 3 · 手动下载

按 [INSTALL.md 第 7 步](INSTALL.md#第-7-步--下载模型权重高清修复功能需要)的表格下载，
放进 `models\`。**最小可用只要一个文件**：

| 放入 `models\` | 体积 | 说明 |
|---|---|---|
| `realesr-general-x4v3.pth` | 4.7 MB | 默认模型，装了它高清修复就能跑 |

想开「人脸修复」再加 `GFPGANv1.4.pth`（332 MB）+ `gfpgan\weights\` 下的两个人脸权重。

## 五、数据与安全

- **数据全部留在本机**：不做任何云端上传；服务仅监听 `127.0.0.1`。
- **数据库结构版本保持 2 不变**：新增字段一律增量加列，绝不重建全表。
- **采集是「替换式记录」**：同一次采集会先清理所选账号的既有作品记录再重新采集。
  因此启动采集**必须明确指定账号或地区**，空请求会被拒绝 —— 这是刻意设计，
  避免「参数缺省就默默扩大范围」导致误删。
- ⚠️ **采集途中关窗会留下空缺**：所选账号的旧记录在任务**开始时**就统一清掉，
  之后才逐个采集。若在采完前关闭程序（或在途中取消），**排在后面的账号**会处于
  「旧记录已删、新记录未采」的空状态 —— 看起来像数据丢了。
  实际并未丢失：这些账号下次采集时会自然补齐，也可从 `backups\` 的当日备份恢复。
  建议**一次采集就让它跑完**；若确实要中断，下次重新采一遍这些账号即可。
- **串行采集**：采集任务串行执行，避免并发触发平台限流。
- **自动备份**：程序每天首次启动时会把数据库备份到 `backups\`。
- **隐私**：程序不会把账号昵称、UID 等信息写入日志或导出到本机以外。

## 六、常见问题

**Q：采集没有结果 / 卡住不动？**
采集依赖网络与代理。默认走本机代理 `http://127.0.0.1:11304`；
可在「设置 → 采集」里修改或测试连通性。另外浏览器内核需要一个已登录的账号
登录态（`data\sessions\`，随程序一起迁移，通常无需重新登录）。

**Q：换了一台电脑打不开 / 采集失败？**
浏览器内核已随程序内置（`runtime\ms-playwright\`，437 MB），程序启动时会自动
优先使用它，不依赖系统里是否装过 Playwright。**只要拷贝整个程序文件夹带走即可。**
（自检命令：`venv\Scripts\python.exe scripts\verify_bundled_browser.py`）

**Q：采集到一半关掉程序，某些账号的作品不见了？**
见上文「数据与安全 → 采集途中关窗会留下空缺」。这些账号下次采集即可补齐，
或从 `backups\` 当日备份恢复。

**Q：高清修复很慢？**
超分走 GPU（Real-ESRGAN）。显存不足时可在「高清修复」里调小分块尺寸，
或改用更轻量的模型。CPU 模式会慢 5～10 倍。

**Q：为什么程序这么大？**
主要是 PyTorch（约 4.1 GB）与超分模型（约 1.2 GB）。
体积换的是「离线可用 + 无需装环境」。如需瘦身可用 CPU 版 torch，代价是推理变慢。

**Q：配置和下载目录在哪？**
统一配置：程序根 `config.json`。
去水印下载配置与历史：`data\download\`（会自动从旧的
`%APPDATA%\TikTokNoWatermark\` 迁移）。

## 七、从源码运行（开发）

**完整的分步说明见 [INSTALL.md](INSTALL.md)** —— 含环境要求、依赖安装顺序、
模型权重下载清单与排错。这里只给最小路径：

```bat
:: 1) 虚拟环境（Python 3.10 64 位）
python -m venv venv

:: 2) ★ 先装 PyTorch（GPU 版选 cu128；CPU 版换 --index-url .../whl/cpu）
venv\Scripts\python.exe -m pip install ^
    torch==2.11.0+cu128 torchvision==0.26.0+cu128 ^
    --index-url https://download.pytorch.org/whl/cu128

:: 3) 其余依赖（此时 pip 不会再重复拉 torch）
venv\Scripts\python.exe -m pip install -r requirements.txt

venv\Scripts\python.exe -m playwright install chromium

:: 5) 模型权重（也可跳过 —— 程序首次用到时会自动下载）
venv\Scripts\python.exe scripts\fetch_models.py --min
::    ffmpeg 放进 tools\ffmpeg\bin\（仅视频处理需要）
```

- **要用高清修复**：torch + 模型 + ffmpeg 三样都要。

## 八、版本沿革

| 版本 | 说明 |
