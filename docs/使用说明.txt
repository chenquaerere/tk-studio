TK 素材工坊 · TK Studio  v1.4.2   使用说明
================================================================

采集 · 去水印 · 高清修复，一站式素材工作台。
本程序把原「TK 作品链接采集器」与「TK 去水印高清程序」合并为一套应用。


一、怎么启动
----------------------------------------------------------------
双击程序目录里的：   TK素材工坊.exe

启动器会在托盘区就位，自动拉起本地服务并打开程序自己的窗口。
窗口关掉后程序即退出，可在托盘图标上右键选择「打开界面」或「退出程序」。

如果双击没反应或界面空白，看程序目录下的两个日志：
    launcher.log   启动器的日志
    app.log        主程序的日志


二、界面怎么用（左侧导航分四组，共 16 个页面）
----------------------------------------------------------------
【总览】
  · 仪表盘      账号 / 作品 / 任务 / 聊天采集的整体情况（只读统计）
                有未完成任务时会出横幅，一键跳去「采集任务」恢复
                账号为 0 时显示三步上手引导

【采集工作流】（按实际操作顺序排列）
  · 账号管理    增删账号、设置地区分类、刷新昵称
                支持状态筛选、全选 / 全不选 / 反选、批量启用停用
                支持从 文本 / CSV / Excel 文件批量导入（先读取再确认）
  · 聊天链接采集 采集好友 / 群聊里分享的视频链接
                首次使用先点「登录账号」人工登录一次，之后长期免登录
                「最近使用」胶囊点一下即切换目标；可导出 TXT、清空单目标链接
  · 采集任务    选账号（可按地区批量勾选）→ 设每个账号采集几条 → 开始采集
                可设记录日期（今天 / 昨天）、账号间隔，采集中可暂停 / 继续
                跑完若有失败账号可一键重试；有没跑完的任务可「恢复未完成」
  · 采集结果    查看本次或历史采集到的作品链接
                可按发布日期 / 状态 / 关键词筛选，可按账号分组导出
                点任意一行即复制该条链接
  · 每日归档    按日期看已采到的链接
  · 历史记录    历次采集任务的台账：点任意一行看该任务的账号明细与全部链接

【素材制作】
  · 去水印      粘贴 TikTok 链接 → 解析 → 下载无水印视频或图集
                下载区可选「保存目录」
  · 高清修复    把图片 / 视频做超分放大（Real-ESRGAN），可选人脸修复
                处理参数区可选「保存目录」
  · 素材库      浏览已下载的素材（手机上长按图片即可存进相册）
  · 模型中心    查看可用模型与显存占用

【系统】
  · 任务中心    正在跑 / 刚跑完的任务，进度与日志
  · 工具箱      代理测试等常用工具
  · 运行日志    看程序日志（默认末尾 500 行），按级别筛选并着色
                可打开日志目录、复制、导出
  · 设置        代理、采集参数、聊天条数、历史 / 日志保留天数
                「数据维护」里可立即备份、从备份恢复、查看只读目录位置
  · 关于        版本信息与本程序的更新日志


三、几件必须知道的事
----------------------------------------------------------------
1. 采集是「替换式记录」
   同一次采集会先清掉所选账号的既有作品记录，再重新采集。
   所以启动采集必须明确选好账号或地区，空请求会被拒绝 —— 这是刻意设计，
   避免「参数缺省就默默扩大范围」把别的东西误删。

2. ⚠️ 采集到一半关掉程序，某些账号的作品会「不见了」
   所选账号的旧记录在任务一开始就统一清掉，之后才逐个账号采集。
   如果在采完前关窗（或中途取消），排在后面的账号就会处于
   「旧记录已删、新记录还没采」的空状态 —— 看起来像数据丢了。

   数据并没有真正丢失：
     · 这些账号下次重新采集即可补齐；
     · 也可以从程序目录 backups\ 里的当日备份恢复。
   建议：一次采集就让它跑完。

3. 数据全部留在本机
   程序不做任何云端上传。本地服务默认只监听 127.0.0.1；
   只有你在「设置」里勾选「允许局域网访问（手机）」并重启之后，
   才会监听 0.0.0.0 —— 那时同一网络内的设备都能访问本程序
   （可解析、下载、查看结果文件），请只在可信网络里开启。

4. 每天首次启动会自动备份一次数据库到 backups\ 目录。

5. 手机上怎么把素材存进相册
   手机连上同一 WiFi，打开「设置 -> 局域网 / 手机访问」里显示的地址，
   进「素材库」或「下载结果」区 —— 每张卡片下有「打开 / 下载」两个按钮：
     · iPhone：点「打开」看大图，再长按图片，选「存储到照片」；
     · 安卓：点「下载」，文件进 Download 后系统图库会自动收录。
   网页本身没有「批量写入相册」的权限（这是浏览器的安全限制，
   只有系统分享面板或原生 App 能写），所以只能这样逐张来。

6. 想「一键保存到相册」或「整批存」怎么办
   v1.5.0 新加了内置 HTTPS。手机端那个能一键存相册的按钮（调系统
   分享面板，也可顺手分享到抖音 / 微信）用的是浏览器的 Web Share API，
   而该 API 只在 HTTPS 下存在 —— 局域网 http 地址上浏览器干脆不提供。

   开法（一次配置，之后一直有效）：
     a) 「设置 -> 局域网 / 手机访问」勾选「启用 HTTPS」→ 保存 → 重启程序；
     b) 重启后在同一张卡片上点「下载证书」，按提示在手机上下载；
     c) 手机：设置 -> 通用 -> VPN与设备管理 -> 安装该描述文件；
     d) 手机：设置 -> 通用 -> 关于本机 -> 证书信任设置 -> 打开它的
        「完全信任」（这一步不做，浏览器仍会报证书无效）；
     e) 之后用设置页显示的 **https** 地址打开，点开素材大图，
        底部就会多出「保存到相册」。

   证书是程序在你本机自己签的（不是买来的），只用于这个内网地址；
   私钥只存在程序目录的 runtime\tls\ 里，不会外传。
   换了 WiFi / 换了网卡后地址会变，程序会自动重新签一张；
   也可以手动点「重新生成证书」（生成后要重启，手机需重装一次）。

   不想装证书也行 —— 还有一条**完全不需要证书**的路：iOS 快捷指令，
   可以把素材库整批存进相册。按 docs\iOS快捷指令.md 里的配方搭一次。
   安卓不需要：点「下载」后系统媒体扫描会自动收进图库。


四、换台电脑怎么办
----------------------------------------------------------------
直接把整个程序文件夹拷贝过去即可，不需要在那台电脑上装任何东西：

  · 自带 Python 运行时与全部依赖；
  · 自带浏览器内核（runtime\ms-playwright\，437 MB）—— 那台电脑即使
    从没装过 Python 或 Playwright，也能直接采集；
  · 自带 21 个账号的浏览器登录态（data\sessions\），通常无需重新登录；
  · 启动器是 .NET Framework 4.8 程序，Windows 10 / 11 系统自带。

想自检浏览器内核是否正常：
    venv\Scripts\python.exe scripts\verify_bundled_browser.py


五、采集连不上 / 没有结果
----------------------------------------------------------------
采集走系统网络，默认不使用任何代理；需要代理时进「系统 → 设置 → 采集设置」自己配。
最快的办法是点「自动检测本机代理」—— 程序会读系统代理、环境变量和本机常见代理端口，
逐个真实发请求验证，把能用的列出来（带出口 IP 与延迟），点「使用」再「保存采集设置」即可。
也可以手动填主机 + 端口，或点「粘贴完整地址」把代理商给的整串
（形如 http://user:pass@host:port）粘进来自动拆分。
代理要求账号密码时，必须填「用户名 / 密码」两个框，否则会报「需要认证 407」。
填完点「测试连通」确认能出网（会显示出口 IP），再保存。
登录态过期时，在「账号管理」里刷新昵称即可确认（刷新失败通常就是掉登录了）。


六、程序目录里都有什么
----------------------------------------------------------------
  TK素材工坊.exe          启动器（双击这个）
  desktop.py              桌面入口：起本地服务 + 开窗口
  config.json             统一配置（app / collector / watermark / hd 四分区）
  _app\                   应用代码（采集内核 / 去水印内核 / 服务层 / 网页界面）
  venv\  python-runtime\  依赖环境与内置 Python
  runtime\ms-playwright\  随身浏览器内核
  models\  tools\  gfpgan\ 超分模型 / ffmpeg / 人脸修复
  data\                   ★ 你的数据：数据库 + 浏览器登录态 + 下载配置
  downloads\ exports\     下载产物 / 导出结果
  backups\                数据库备份
  logs\                   运行日志
  docs\ README.md         文档


七、体积说明
----------------------------------------------------------------
程序约 8.2 GB，主要是 PyTorch（约 4.1 GB）与超分模型（约 1.2 GB），
再加上浏览器内核 437 MB。这些换来的是「离线可用 + 换机免装环境」。
