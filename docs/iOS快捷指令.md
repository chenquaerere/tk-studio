iOS 快捷指令配方 —— 把素材**整批**存进相册
=============================================

为什么需要这个
----------------
网页**没有**批量写入相册的权限，这是 iOS / 安卓的隐私设计。
浏览器能给的最优解只有两条：

1. **长按图片 → 存储到照片** —— 零门槛，但只能**一张一张**来；
2. **系统分享面板**（网页里的「保存到相册」按钮）—— 也要一张一张点，
   而且那条路必须开 HTTPS。

真正能「一次十几张全进相册」的，只有**原生侧**：
iOS 就是「快捷指令」，安卓是系统下载器（安卓点「下载」后媒体扫描会自动收进图库，
所以**安卓不需要这份文档**）。

这条思路不是我发明的 —— 47k star 的同类项目 copyparty 也是这么做的
（它的 README 原话：*there is no iPhone app, but the following shortcuts are
almost as good*）。**它走的是普通 http，不需要装任何证书。**


前提（先做这三步）
--------------------
1. 电脑上打开程序 → 设置 → 勾选 **「允许局域网访问（手机）」** → 保存 → **重启程序**。
2. 设置页点 **「显示手机访问地址」**，看到形如 `http://192.168.0.1:7860/` 的地址。
   下面所有配方里的 `http://192.168.0.1:7860` 都换成**你自己的那个**。
   ⚠️ 端口是每次启动随机分配的，**重启程序后地址会变** —— 地址变了要回来改快捷指令。
3. 手机连**同一个 WiFi**，用 Safari 打开这个地址，确认能看到界面。


配方 A：把「素材库」里的图片和视频整批存进相册
------------------------------------------------
> 适用：`素材 → 素材库` 里能看到的那一批（最多 300 个）。

先在电脑上看一眼素材库接口长什么样 —— 它返回的就是下面这些字段，
配方里的每一步都直接取这里的键名，**没有猜的**：

```json
{
  "rows":    [["10-13 16:03", "JPG", "1.4 MB", "C:\\...\\xxx.jpg"], ...],
  "items": [
    {
      "name": "1791878622599_IMG20261012181309_v3.jpg",
      "url": "/api/file?path=C%3A%5CUsers%5C...jpg",      ← 原文件（下载用）
      "preview_url": "/api/file?inline=1&path=...",       ← 浏览器内直接打开
      "kind": "image",  "is_image": true,  "is_video": false,
      "size": 1445897
    }
  ]
}
```

### 快捷指令怎么搭（新建一个快捷指令，按顺序加动作）

| # | 动作（Shortcuts 里的中文名） | 设置 |
|---|---|---|
| 1 | **获取 URL 内容**（Get Contents of URL） | URL 填 `http://192.168.0.1:7860/api/library`；方法 `GET` |
| 2 | **从输入获取字典值**（Get Dictionary Value） | 获取 `items`，输入 = 上一步结果 |
| 3 | **重复每个项目**（Repeat with Each） | 输入 = 上一步得到的列表 |
| 4 | **如果**（If） | 条件：**从输入获取字典值** 取 `is_image`（输入用「重复项目」）是 `true` |
| 5 | **从输入获取字典值** | 获取 `url`，输入 = 「重复项目」（得到形如 `/api/file?path=...`） |
| 6 | **文本**（Text） | 写 `http://192.168.0.1:7860`，然后把第 5 步的变量紧跟在后面（不加空格、不加斜杠） |
| 7 | **获取 URL 内容** | URL = 上一步的文本 |
| 8 | **存储到相册**（Save to Photo Album） | 输入 = 上一步下载到的文件 |
| 9 | **结束如果** / **结束重复** | —— |

搭好后点运行，第一次会问「允许访问你的照片」→ 允许。
之后每次运行就是「打开快捷指令 → 点一下 → 等着」。

### 只想要其中一类？
把第 4 步的条件换成 `is_video` 是 `true` 就是**只存视频**；
把第 2 步的 `items` 换成 `rows` 可以拿到底层的列表格式（一般用不到）。

### 想要自定义文件名？
第 6 步之前加一步 **文本**：`IMG_` + （第 5 步旁边的 `name` 变量），
然后「重命名文件」再存储。不加也没关系，存进相册后相册按拍摄时间排序，
文件名不影响使用。


配方 B：把「下载全部（ZIP）」那包直接拆进相册
----------------------------------------------
> 适用：刚在「去水印」跑完一批，结果区已经生成了 `TK下载_时间戳.zip`。
> 这条更省事，但**只对图片有效**（视频要先存下来再单独处理）。

1. 手机上用 http 地址打开程序 → 去水印页 → 跑完或找到结果区；
   长按 **「下载全部（ZIP）」** → 「拷贝链接」（形如
   `http://192.168.0.1:7860/api/file?path=...TK%E4%B8%8B%E8%BD%BD_xxx.zip`）。
2. 快捷指令：
   | # | 动作 | 设置 |
   |---|---|---|
   | 1 | **文本** | 粘贴上一步拷贝的链接 |
   | 2 | **获取 URL 内容** | URL = 上一步 |
   | 3 | **解压缩**（Extract Archive） | 输入 = 上一步得到的文件 |
   | 4 | **重复每个项目** | 输入 = 解压结果 |
   | 5 | **如果** | 文件扩展名 是 `jpg` 或 `png`（用「或」多条件） |
   | 6 | **存储到相册** | 输入 = 「重复项目」 |
   | 7 | **结束如果** / **结束重复** | —— |


常见问题
----------
**Q：第 1 步就报「无法连接到服务器」**
地址或端口不对。端口每次启动都会变，回程序设置页重新点「显示手机访问地址」核对。
也确认手机和电脑在同一个 WiFi（手机显示 4G/5G 而没连 WiFi 就会失败）。

**Q：报「App Transport Security」/ 拒绝明文 http**
从 iOS 17 起，快捷指令访问**局域网内的** http 地址通常没问题；
若被拦，把地址里的 IP 换成电脑主机名试试，或在路由器上给电脑固定 IP。
（这也是为什么程序里另外做了 **HTTPS** 那条路 —— 需要装一次自签证书，
但换来的是网页内直接出现「保存到相册」按钮，不用配快捷指令。）

**Q：跑一半停了 / 有的图没存上**
一次几百张会很久（每张约 1～2 秒），且 iOS 必须保持快捷指令在前台。
建议一次 30～50 张：先在素材库里把要的部分准备成单独目录，
或者用配方 B（一次一包 ZIP）。

**Q：相册里出现了重复**
快捷指令不做去重，重复运行就会重复存。删掉即可。

**Q：我不想配快捷指令**
那就在手机上用 http 地址打开素材库，**长按图片 → 存储到照片**，逐张存；
或者勾好素材后点「下载全部（ZIP）」，在「文件」App 里解压，
全选图片 → 共享 → 存储图像。能行，只是步骤多一些。
